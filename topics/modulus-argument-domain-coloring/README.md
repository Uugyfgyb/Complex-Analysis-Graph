# 模与辐角：长度、方向和域着色

打开 [index.html](./index.html) 即可离线使用。拖动复平面中的蓝点，或输入实部、虚部和乘数参数；点击三张颜色图可同步选点。源图为用户本次提供的 [1600 × 911 PNG](./source/original.png)，保留在仓库里便于逐项对照。

## 数学约定

- `z=x+iy`，`|z|=sqrt(x²+y²)`；非零点的主辐角 `Arg z∈(−180°,180°]`。从正实轴逆时针为正。
- `w=ρe^{iφ}`，`|zw|=|z|ρ`，`Arg(zw)≡Arg z+φ (mod 360°)`。
- `z≠0` 时，`1/z=(x−iy)/(x²+y²)`，`|1/z|=1/|z|`，`Arg(1/z)≡−Arg z (mod 360°)`。
- 模地形画的是实数 `log₂|z|`。复对数的所有值为 `ln|z|+i(Arg z+2πk)`，其中 `k∈Z`；两者不可混同。
- 原点没有辐角；原点处的倒数和 `log₂|z|` 也未定义。

## 原图数值核对

对 `z=1.5+1.2i`：`|z|=sqrt(3.69)≈1.92094`，`Arg z≈38.65981°`，`log₂|z|≈0.94181`。原图的倒数 `≈0.42−0.33i` 是粗略示意；精确式为 `(50−40i)/123`，计算值 `≈0.40650−0.32520i`。原图的乘法另用 `z₁=1.6e^{i35°}` 和 `z₂=1.0e^{i70°}`，故乘积为 `1.6e^{i105°}`；交互页默认 `z` 不同，不能把两组读数直接相等。

## 颜色图与范围

三图都取 `f(z)=z`，范围为 `Re z, Im z ∈ [−2.2,2.2]`。色相由 `Arg z` 映射，域着色的明暗按 `0.43+0.15 cos(2π log₂|z|)` 变化。模地形另用归一化的 `log₂|z|` 和小幅周期条纹。颜色只是编码规则；零点附近由有限像素采样，图像边缘也会截断等值线。标注圆的半径为 0.5、1、2；数值判断以解析式和实时读数为准。
